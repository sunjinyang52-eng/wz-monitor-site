# 王者荣耀 · 更新与舆情监控

内部共享的单页监控看板，每天上午 10:30 更新数据。

## 当前页面结构

- **值得推荐**：展示本期最值得关注的正向玩法，以及需要持续跟踪的舆情争议。
- **舆情表现**：仅保留近 7 日话题讨论热度榜，用排名回答“大家本周都在讨论什么”。
- **更新内容**：按玩法、商业化、运营活动的顺序汇总完整更新。
- 桌面宽屏右侧提供三段快捷导航；移动端自动切换为单列布局。

## 数据维护

- 页面为纯静态单文件 `index.html`，无需后端。
- 日常更新入口位于 `index.html` 底部的 `const DATA = {...}`。
- 数据来源为公开更新信息、社区平台与有数舆情汇总；跨平台点赞仅作外部表现参考。
- 未核实爆料不进入正式更新列表。

## 本地预览

在仓库目录启动静态服务后访问：

```text
http://127.0.0.1:8766/
```
