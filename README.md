# 王者荣耀 · 更新与舆情监控

内部共享的单页王者日报，每天上午 10:30 更新。

## 当前页面结构

- **8.12 王者日报**：只保留“更新公告监控”和“舆情监控”两块内容，全部按单行列表展示；舆情亮点用金色五角星标记。
- 8.12 正文保留当日来源稿的详细原话，不自行压缩，只做结构化排版。
- **8.11 王者日报**：保留原有完整看板，包括值得关注、近期话题讨论度和更新内容。
- 右上角可筛选已有日报日期；桌面宽屏支持两侧箭头翻页，移动端箭头自动收进日期选择器两侧。
- 右侧快捷导航会随日报类型自动切换；移动端自动变为单列布局。

## 数据维护

- 页面为纯静态单文件 `index.html`，无需后端。
- 日常更新入口位于 `index.html` 底部的 `const REPORTS = {...}`；新增日期时追加一份报告，旧日报不要覆盖。
- 普通每日变化使用 `layout: "brief"`；需要保留完整周报结构时使用 `layout: "full"`。
- 数据来源为公开更新信息、社区平台与有数舆情汇总；跨平台点赞仅作外部表现参考。
- 未核实爆料不进入正式更新列表。
